SERAPH-YARA-005 · yara · critical

MCP config places a secret environment variable on a network sink

Detects an MCP client config that sends a well-known API token to a host that is not that token's vendor, or pipes printenv into a fetch utility. A token used against its own vendor API does not match. A lookalike host such as github.com.attacker.example is not the vendor. Content-only rule: it compiles with no externals.

ScopeMCP client configs: an mcpServers object, Codex mcp_servers tables, a VS Code servers object beside a command key, or Zed context_servers. Presence of a token variable in an env map is not enough. File types are JSON, JSONC, TOML, and YAML, any case, including .claude.json, *.json.bak, and *.json.backup*. Markdown does not match. The Forge rule has no path. It needs a JSON object at the start of the file (after an optional BOM or blank space), a top-level mcpServers: key, or an mcp_servers table. A JSONC file that opens with a comment, and Markdown, do not match.

False positives

  • A proxy or mirror of a vendor API on another host. An AWS secret beside any URL matches, because that secret signs requests and is not sent.

References

  • https://attack.mitre.org/techniques/T1567/

Threat

MCP servers often receive a token in an environment map so they can call their own vendor. That is normal. It is not normal for the command line to interpolate that variable into a URL, or to pipe the environment into a fetch utility.

Why this rule

The rule requires the MCP server map and one of three shapes: a fetch utility followed by a $NAME or ${NAME} for a short list of well-known token variables, the same interpolation inside a URL, or printenv piped into a fetch. An environment map that merely holds a placeholder token, with a local node command, is the negative. The dollar sign is the difference.

Limitations

The name list is finite. A custom variable will not match. A command that reads the token in a child process and posts it without those names will not match. A command that sends a named token to that vendor's own host does not match. A different host still does, including a lookalike such as github.com.attacker.example. An AWS secret has no vendor host and matches beside any URL.

Triage

The destination host matters more than the variable name. If the host is not the vendor that token belongs to, rotate the token and delete the entry.
