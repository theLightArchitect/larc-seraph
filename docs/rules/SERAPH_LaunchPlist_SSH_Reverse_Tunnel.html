SERAPH-YARA-009 · yara · critical

LaunchAgent plist opens an SSH reverse tunnel with host-key checking off

Detects a launchd plist that runs ssh with a reverse forward and StrictHostKeyChecking set to no, either as separate argument strings or as one command line.

AuthorKevin Francis Tan · Light Architects
Date2026-11-13
ATT&CKT1572, T1021.004, T1543.001
Tacticcommand-and-control, lateral-movement, persistence
LicenseDetection Rule License 1.1
ScopeLaunchAgent and LaunchDaemon plists. A live ssh process is covered by the companion Sigma rule.

False positives

  • An administrator who deliberately disables host-key checking on a reverse tunnel and encodes that choice in a plist. accept-new and yes do not match.

References

  • https://attack.mitre.org/techniques/T1572/
  • https://attack.mitre.org/techniques/T1021/004/
  • https://attack.mitre.org/techniques/T1543/001/

Threat

A reverse forward makes a remote host reach back into this machine. Turning host-key checking off means the client will accept a changed or unknown key. Together, in a launchd job, that is a path in that does not depend on the operator being present and does not depend on the remote key staying the one that was trusted last time.

Why this rule

The plist has to name ssh and a reverse-forward flag and the disabled host-key option, either as separate argument strings or as one command line. accept-new and the default checking mode do not match. A disabled check without a reverse forward does not match. The companion Sigma rule watches the running process, including when the parent is launchd rather than an editor.

Limitations

An administrator who encodes this exact choice in a plist will match. The option can also be hidden in a config file that ssh reads by default, which this rule does not open. ATT&CK T1572 and T1021.004 describe the tunnel and the protocol. T1543.001 describes the persistence wrapper.

Triage

This is a path in. Confirm with the operator whether they disabled host-key checking on purpose. If not, unload the job and review authorized_keys.
