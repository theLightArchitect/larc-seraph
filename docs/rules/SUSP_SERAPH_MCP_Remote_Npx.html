SERAPH-YARA-004 · yara · high

MCP config runs npx or uvx from a remote or floating tag

Detects an MCP client config that invokes npx, uvx, or npm exec against a URL, a github: specifier, a git+ specifier, or a moving dist-tag such as @latest or @next. bunx, pnpm dlx, and yarn dlx count as runners. Content-only rule: it compiles with no externals.

ScopeMCP client configs: an mcpServers object, Codex mcp_servers tables, a VS Code servers object beside a command key, or Zed context_servers. File types are JSON, JSONC, TOML, and YAML, any case, including .claude.json, *.json.bak, and *.json.backup*. Markdown does not match. The Forge rule has no path. It needs a JSON object at the start of the file (after an optional BOM or blank space), a top-level mcpServers: key, or an mcp_servers table. A JSONC file that opens with a comment, and Markdown, do not match.

False positives

  • An intentional @latest pin during a review, and any registry package whose name happens to sit within 180 characters of a URL in the same server entry. The stock npx -y scoped package with no tag is not a match.

Threat

npx and uvx will fetch code at start time. A registry package with a version is a choice you can pin. A URL, a github: or gitlab: specifier, a git+ specifier, or a moving dist-tag such as @latest or @next is a choice that moves whenever the remote moves.

Why this rule

The rule requires the MCP server map and one of those specifiers within a short window of npx, uvx, or npm exec. The official filesystem server invoked as a scoped package with no tag is a negative fixture. So is a package whose name contains the word github but not the github: specifier, and so is a version pin such as @0.6.0.

Limitations

@latest is sometimes what an operator typed on purpose during a review. That branch is noisier than the URL branch, and the severity is still high because the two shapes share one rule. Unpinned registry names with no tag are not matched. That omission is deliberate: it is the published quickstart, and a rule that flags it would train people to ignore the pack. Track those with a lockfile policy, not with this signature.

Triage

The package specifier is the decision. A quoted URL, a github: specifier, or @latest means the code can change. Pin it or remove it.
